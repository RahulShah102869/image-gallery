# 🖼️ Image Gallery – Responsive Web Application

Welcome to my Image Gallery project! 👋

A modern and responsive image gallery web application built using HTML, CSS, and JavaScript. It allows users to explore, search, and filter images through a clean and interactive interface.

## 🌐 Live Demo

🔗 **Website:** [View Image Gallery](https://image-galleryv1.netlify.app/)

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Interactive functionality
- **Netlify** – Website hosting and deployment

## ✨ Features

- Responsive image gallery layout
- Category-based image filters
- Image search functionality
- Pagination for browsing images
- Lightbox functionality for viewing images
- Modern and user-friendly interface
- Smooth browsing experience
